Sean Garner, the creator of the Men's Health 6-Week Sweat Off program for the All Out Studio streaming fitness platform, hosted another live home workout session at home. For this routine, you'll need a pair of weights—but don't be discouraged if you don't have a set of dumbbells available. You can use whatever you have on hand, like Garner, who filled up some water jugs to use as a load.

Like Garner's last session, this workout will challenge you with progressively longer work periods as you move through the workout. Take 10 seconds between each set, and remember that you're tacking on extra time for each period.
